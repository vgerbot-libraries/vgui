本指南创建一个带单个按钮、同时支持原生和 WebAssembly 的计数器。示例包含所有 import 和初始化步骤，可以直接复制到新项目，不需要额外的框架设置。

开始之前，请先完成[安装](../installation/)中的前置准备。

## 1. 创建项目

```bash
cargo new vgui-counter --bin
cd vgui-counter
```

## 2. 添加依赖

将 `Cargo.toml` 替换为以下清单。vgui 和 GPUI 目前使用 Git 依赖：

```toml
[package]
name = "vgui-counter"
version = "0.1.0"
edition = "2021"

[dependencies]
vgui = { git = "https://github.com/vgerbot-libraries/vgui" }
gpui = { git = "https://github.com/zed-industries/zed" }
gpui-platform = { git = "https://github.com/zed-industries/zed", package = "gpui_platform" }

[target.'cfg(target_family = "wasm")'.dependencies]
wasm-bindgen = "0.2"
```

`gpui-platform` 提供下面使用的原生及浏览器应用入口，`wasm-bindgen` 暴露浏览器启动函数。保留生成的 `Cargo.lock`，使后续构建在主动更新之前使用同一组已解析版本。

## 4. 运行

```bash
cargo +nightly run
```

首次构建可能需要较长时间，因为 Cargo 还会编译 GPUI 及其原生依赖。请在桌面会话中运行该命令；无显示器的构建环境不能显示窗口。

## 各部分如何协作

- `application()` 创建原生 GPUI 应用，`run` 启动事件循环。WebAssembly 则通过 `single_threaded_web()` 和 `run_embedded` 管理浏览器生命周期。
- `open_window` 配置原生窗口，并将窗口与应用上下文传给 vgui；浏览器 canvas 为 WebAssembly 提供视口。
- `vgui::mount` 将 `app` 安装为该窗口内渲染的根视图。
- `create_signal` 创建计数，`count.get()` 显示计数，点击处理器通过 `set_count.update` 将其递增。
- `class` 字符串包含 vgui 支持的 Tailwind 风格工具类，不需要浏览器样式表。

同一程序会在文档工作流中进行原生及 WebAssembly 编译，预览的 canvas 渲染和 Increment 点击交互由浏览器测试覆盖。原生窗口交互需要桌面会话，不包含在这些测试中。
